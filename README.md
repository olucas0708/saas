# SAAS

me de um projeto da criaçao de um SAAS q vou fazer q cria sites nesse saas
Qualquer pessoa sem conhecimento técnico — estruture o projeto para criar sites de forma simples, sem precisar programar.
Comece a construir o MVP pelo editor visual de arrastar e soltar, com modelos prontos e uma prévia do site.

This project was built with [Lovable](https://lovable.dev).
